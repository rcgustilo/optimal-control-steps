# Optimal & MPC Steps

An offline Android app for learning optimal control and Model Predictive Control (MPC) at a slow pace.

The course has 8 modules and 32 lessons, in this order:
1. Optimization basics
2. Constrained optimization (Lagrange multipliers, KKT conditions, quadratic programming)
3. Dynamic programming and the Riccati recursion
4. LQR
5. Pontryagin's principle and bang-bang control
6. MPC fundamentals
7. Constrained MPC
8. Applications

The app includes formulas, tables and quizzes, plus these simulations:
- Gradient descent and Newton's method
- Riccati gain convergence
- LQR on a double integrator
- Minimum-time switching curve
- Constrained MPC compared with a rate-limited unconstrained controller

Progress tracking covers your streak, a daily goal, charts and a list of lessons worth reviewing.

GitHub Actions builds the APK. Download it from the **Releases** page.
